Open WebUI Replica Developed a replica of the Open WebUI interface, integrated with local LLMs via LM Studio. Leveraged the Platform5 web application to bridge the backend models with a seamless user interface.

## Overview

This repository contains the source code and supporting files for **Platform-5**.

## Getting started

```bash
git clone https://github.com/Thousifibrahim/Platform-5.git
cd Platform-5
```

Check the repository files for the project-specific entry point and setup requirements. Do not commit credentials, API keys, or private configuration files.
